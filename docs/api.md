# API reference

The public API is exported from `wxdiagram`. The most-used modules are
`wxdiagram.core` (shapes, canvas, diagram), `wxdiagram.lines` (edges and
arrowheads), `wxdiagram.composite` (composite shapes and constraints), and
`wxdiagram.persistence` (JSON).

::: wxdiagram
    options:
      members: true
      show_submodules: false
